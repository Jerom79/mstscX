# Интерфейс

Заголовки верхнего меню выводи только текстом. Добавляй к каждому новому пункту внутри выпадающих, вложенных и контекстных меню иконку, соответствующую его действию или назначению. Используй системные значки WinUI, где они подходят. Для одинаковых действий в разных меню используй одинаковые иконки.
