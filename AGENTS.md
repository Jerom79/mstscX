# Интерфейс

Заголовки верхнего меню выводи только текстом. Добавляй к каждому новому пункту внутри выпадающих, вложенных и контекстных меню иконку, соответствующую его действию или назначению. Используй системные значки WinUI, где они подходят. Для одинаковых действий в разных меню используй одинаковые иконки.

# Языковая поддержка

При каждой доработке учитывай русский и английский языки приложения и установщика.

- Новые и изменённые пользовательские тексты добавляй в `mstscX/Resources/Localization/en.json`: русский исходный текст — ключ, английский перевод — значение.
- В C# используй `Services.L.T` для текста и `Services.L.F` для сообщений с параметрами. В XAML используй `loc:Text` с ключом, полученным через `L.Key`. Переводи также подсказки, подписи доступности, варианты списков, сообщения ошибок и подтверждения.
- Не переводи пользовательские названия серверов, адреса, логины и другие данные профилей. Сохраняй параметры форматирования в обоих переводах.
- Сообщения установщика добавляй на обоих языках через `TextLang` или `[CustomMessages]`.
- Системный язык по умолчанию: русский для русского языка интерфейса Windows, английский для всех остальных. Явный выбор пользователя сохраняется; смена языка приложения применяется после перезапуска.
- После изменений текстов запускай `tests/LocalizationTests` и проверяй, что оба языка имеют переводы и одинаковые параметры сообщений. Проверяй компоновку с учётом длины английских и русских подписей.
